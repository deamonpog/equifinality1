# Measuring Equifinality: Conformal Rule Identification in Agent-Based Models

Code, rule library, trained models and result files for

> Chathura Jayalath, William Rand, and Ivan Garibay. *Measuring Equifinality: Conformal Rule Identification in Agent-Based Models.* Computational Social Science Society of the Americas (CSSSA) Annual Conference, 2026.

Different behavioral rules in an agent-based model can generate indistinguishable macroscopic patterns. We treat inverse generative social science as classification over a library of candidate rules and apply conformal prediction (RAPS) to the classifier. Under exchangeability, the resulting set of rules contains the generating rule with probability at least 1 − α, so its size is a calibrated measure of equifinality relative to the rule library and the classifier.

The repository covers the three case studies of the paper:

1. **Schelling segregation.** 2,089 behaviorally distinct utility rules (arithmetic expression trees over six factors) and a transformer classifier over lattice snapshots.
2. **Collective motion.** Eleven neighbor-selection rules for five agents with burst-and-coast dynamics. Covers random forests, a GRU and transformers, and also conformal set size against observation length and a field-representation control.
3. **Transfer to physical robots.** The simulation-trained models applied to robot trajectories, with simulation-calibrated and robot-recalibrated conformal sets.

## Quick check (no data, no GPU)

All result files behind the tables and figures are included. To compare every number reported in the paper against them:

```bash
pip install -r requirements.txt
python scripts/paper_numbers.py
```

The script checks 206 numbers. All of them match except two rounding-boundary cases, which differ by one unit in the last digit: the temporal gain at T = 16 (0.2227, reported as 0.222 from rounded table entries) and the random-3 robot distance (0.2845, reported as 0.285).

## Installation

Python 3.10 or later; tested with Python 3.11 and 3.13 and PyTorch 2.11–2.14.

```bash
git clone https://github.com/deamonpog/equifinality1.git
cd equifinality1
pip install -r requirements.txt
```

Install a CUDA build of PyTorch to train the models (see pytorch.org). All scripts are run from the repository root.

## Data

| Data | Source | Location |
|---|---|---|
| Schelling rule library (2,089 rules) | this repository | `data/schelling/tree_library.json` |
| Schelling simulations (2,089 rules × 100 runs, about 8 GB) | regenerated by `reproduce/schelling.sh` | `GENERATED_DATA/rule_trees/` |
| Collective-motion and robot trajectories | Lei et al. (2020), [doi:10.6084/m9.figshare.11858379](https://doi.org/10.6084/m9.figshare.11858379) | `FISH_DATA/Agents/`, `FISH_DATA/Robots/` |

Each entry of `tree_library.json` gives a rule's class label, its infix expression (for example `(race - dist)` or `(((age * isol) * neigh) + dist)`) and its expression tree. The factor names are `race` (same-type fraction), `age` (neighbor tenure), `dist` (distance from home), `isol` (vacancy fraction), `move` (recent moves) and `neigh` (neighbor utility). The definitions are in `genmod/data/rule_trees.py`.

The trajectory data are not redistributed here. Download the release from figshare and unpack it so that `FISH_DATA/Agents/*.dat` (11 files, one per rule) and `FISH_DATA/Robots/*.dat` (10 files) exist.

## Reproducing the experiments

```bash
bash reproduce/fish_data.sh       # preprocessing and random forests (CPU; the forests take about an hour)
bash reproduce/fish_analysis.sh   # conformal sets, evaluation, Table 2, figures, robots, all numbers
bash reproduce/fish_train.sh      # retrain every collective-motion model (GPU)
bash reproduce/schelling.sh       # Schelling simulation, training and conformal sets (HPC scale)
bash reproduce/schelling.sh --smoke   # small end-to-end check of the Schelling pipeline
```

`fish_analysis.sh` starts from the shipped probabilities and checkpoints, so it reproduces the analyses without retraining. `fish_train.sh` overwrites those files with newly trained models. Set `PYTHON` to choose the interpreter and `WORKERS` to set the number of CPU processes for the Schelling simulation.

Compute used for the paper:
- **Schelling models:** one 48–80 GB GPU each.
- **Collective-motion models:** a single 24 GB GPU; the field transformer needs about 23 GB at batch size 32.
- **Schelling library and simulations:** a CPU cluster.

GPU training is not bitwise deterministic, so retrained models reproduce the reported numbers up to run-to-run variation (fold-to-fold variation in the collective-motion study is about ±0.02). The random forests are seeded, but other scikit-learn versions can shift them in the third decimal: with scikit-learn 1.9, for example, the T = 16 single-agent forest scores 0.253 rather than 0.254. The data preprocessing (`fish_data.sh` steps 01–05) reproduces the shipped splits and windows exactly. The conformal, evaluation and capacity steps reproduce the shipped JSON files exactly from the probability files.

## Implementation notes

- **Experimental unit.** Windows from one simulation run are dependent. Whole runs are assigned to partitions. Collective-motion experiments share initial conditions across rule files, so all eleven runs of an experiment go to the same fold (grouped 5-fold cross-validation over 50 experiments). Evaluation windows do not overlap, and bootstrap intervals resample runs or experiments.
- **Calibration data.** The collective-motion models are trained on 25 experiments per fold, early-stopped and temperature-scaled on 5, calibrated on 10 and tested on 10. For Schelling, the conformal quantile is computed on a random half of the held-out test partition and evaluated on the other half, never on data used for training or model selection.
- **RAPS score.** The randomization term U·p is applied at every rank, including when the true rule is ranked first (`genmod/evaluation/conformal.py`). Omitting it at rank 0 leaves coverage valid but inflates the sets of accurate models. Prediction sets use the same randomized rule and always keep the top-ranked rule. Settings: (k_reg, λ) = (2, 0.1) for collective motion and (5, 0.01) for Schelling.
- **Robot time units.** Positions are normalized by arena radius (0.25 m for simulated agents, 0.42 m for robots). Time is expressed in units of each domain's pooled median kick interval (0.434 s and 0.920 s), computed from the data in `genmod/fish/robots.py`.
